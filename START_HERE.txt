🔧 TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════════

ERROR: "401 Unauthorized" or "Forbidden"
SOLUTION: Check SUPABASE_URL and SUPABASE_ANON_KEY in script.js (lines 8-9)
         Make sure you copied them correctly from Supabase dashboard

ERROR: "Relation 'public.users' does not exist"
SOLUTION: Tables not created yet
         Go to Supabase SQL Editor and run the SQL from SETUP_QUICK_START.txt

ERROR: "User already exists"
SOLUTION: Email already registered
         Use different email or delete test user in Supabase

ERROR: Styles not loading
SOLUTION: style.css not in same folder as HTML files
         Make sure style.css is in root directory

ERROR: Not redirecting to profile after signup
SOLUTION: Check browser console (F12) for error messages
         Make sure Supabase tables are created

For detailed troubleshooting, see SUPABASE_SETUP.md
