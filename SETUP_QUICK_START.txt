📋 QUICK SETUP (5 MINUTES)
═════════════════════════════════════════════════════════════════════════════════

STEP 1: CREATE SUPABASE PROJECT
  1. Go to https://supabase.com
  2. Sign up (free)
  3. Create new project
  4. Wait 2-3 minutes for project creation

STEP 2: COPY CREDENTIALS
  1. Open Supabase dashboard
  2. Go to Settings → API
  3. Copy "Project URL"
  4. Copy "Anon Key"
  5. Open script.js in your project folder
  6. Find lines 8-9 and replace:
     OLD: const SUPABASE_URL = 'https://your-project-url.supabase.co';
     OLD: const SUPABASE_ANON_KEY = 'your-anon-key';
     
     NEW: const SUPABASE_URL = 'YOUR_ACTUAL_PROJECT_URL';
     NEW: const SUPABASE_ANON_KEY = 'YOUR_ACTUAL_ANON_KEY';
  7. Save script.js

STEP 3: CREATE TABLES
  1. In Supabase, go to SQL Editor
  2. Click "New Query"
  3. Copy-paste this code:

═════════════════════════════════════════════════════════════════════════════════
SQL CODE TO CREATE TABLES
═════════════════════════════════════════════════════════════════════════════════

-- Create Users Table
CREATE TABLE public.users (
  id UUID PRIMARY KEY REFERENCES auth.users(id),
  email TEXT UNIQUE NOT NULL,
  phone TEXT NOT NULL,
  shop_name TEXT NOT NULL,
  display_id TEXT UNIQUE NOT NULL,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- Create Products Table
CREATE TABLE public.products (
  id BIGSERIAL PRIMARY KEY,
  user_id UUID NOT NULL REFERENCES public.users(id) ON DELETE CASCADE,
  name TEXT NOT NULL,
  description TEXT,
  price DECIMAL(10, 2) NOT NULL,
  quantity INTEGER NOT NULL DEFAULT 0,
  category TEXT,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- Create Index for Performance
CREATE INDEX idx_products_user_id ON public.products(user_id);

-- Enable Row Level Security
ALTER TABLE public.users ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.products ENABLE ROW LEVEL SECURITY;

-- Create RLS Policies for Users
CREATE POLICY "Users can view own profile"
ON public.users FOR SELECT
USING (auth.uid() = id);

CREATE POLICY "Users can update own profile"
ON public.users FOR UPDATE
USING (auth.uid() = id);

-- Create RLS Policies for Products
CREATE POLICY "Users can view own products"
ON public.products FOR SELECT
USING (auth.uid() = user_id);

CREATE POLICY "Users can insert own products"
ON public.products FOR INSERT
WITH CHECK (auth.uid() = user_id);

CREATE POLICY "Users can update own products"
ON public.products FOR UPDATE
USING (auth.uid() = user_id);

CREATE POLICY "Users can delete own products"
ON public.products FOR DELETE
USING (auth.uid() = user_id);

═════════════════════════════════════════════════════════════════════════════════

  4. Click "Run"
  5. Wait for success message

STEP 4: ENABLE EMAIL SIGNUP
  1. Go to Authentication → Providers
  2. Make sure "Email" is enabled
  3. Optional: Turn on "Autoconfirm New Users" for testing
  4. Click Save

STEP 5: TEST YOUR APP
  1. Open index.html in browser
  2. Click "Sign Up"
  3. Create test account
  4. Should redirect to profile page
  5. Click "Inventory" and add a product
  6. Product should appear immediately

DONE! ✅

🎯 TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════════

ERROR: "401 Unauthorized"
→ Check SUPABASE_URL and SUPABASE_ANON_KEY in script.js

ERROR: "Relation 'public.users' does not exist"
→ Run the CREATE TABLE SQL in Supabase SQL Editor

ERROR: "User already exists"
→ Use different email or delete test user in Supabase

ERROR: No data showing
→ Make sure RLS policies are created

For more help, see SUPABASE_SETUP.md
